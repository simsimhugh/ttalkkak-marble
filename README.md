# 딸깍 마블 (Ttalkkak Marble)

캐릭터를 골라 세계 도시를 사고, 건물을 올리고, 독점하는 4인 3D 보드게임입니다.
사람이 고르지 않은 자리는 AI가 플레이합니다. 설치 없이 브라우저(PC·휴대폰)에서 바로 할 수 있습니다.

**플레이:** https://simsimhugh.github.io/ttalkkak-marble/

## 특징

- **3D 보드** — Three.js(WebGL). 카메라는 맵 가운데 고정, 감정·위기·핵폭탄 때만 잠깐 다가가는 연출(🎥 버튼으로 끌 수 있음). 허브엔 회전하는 지구본과 불 켜진 미니 스카이라인. 화면은 창 크기에 맞춰 항상 꽉 채우고(기준 16:9), ⛶ 버튼으로 전체화면.
- **도시 광장 배경** — 보드는 도시 한가운데 광장에 놓여 있습니다. 블록마다 창문 격자·옥상 급수탑·에어컨·안테나·네온 간판·헬리패드가 다른 건물 수십 동, 순환도로를 도는 차들, 가로등, 가로수, 분수, 벤치, 깃발, 먼 산과 구름. 네 모서리엔 기차역(출발), 호수 위 유배 섬(무인도), 관람차·천막·무대·불꽃놀이(축제), 여행사·헬리포트(세계여행). 테마는 `THEMES` 설정 한 줄로 늘어납니다: 🏙️ 낮의 도시 · 🌃 네온 밤 · 🌇 노을 도시.
- **도시 랜드마크** — 랜드마크(4단계)는 그 도시의 대표 건물 3D 모델입니다(타이베이 101, 왓 아룬, 마리나베이샌즈, 피라미드, 블루모스크, 파르테논, 뉘하운, 스톡홀름 시청, 브란덴부르크 문, 피스타워, 그로스뮌스터, 오페라하우스, 빅벤, 에펠탑, 자유의 여신상, N서울타워…). 같은 모델을 렌더해 각 도시 타일의 배경 그림으로도 씁니다.
- **무인도 호송** — 걸리면 노 젓는 배로 유배 섬까지 실제로 이동해 머뭅니다. 더블 탈출은 쾌속정, 비용 탈출은 요금 보트, 형기 만료는 구조선.
- **건설 연출** — 건물이 땅에서 솟아오르고 먼지가 일며, 랜드마크는 황금 광채. 말이 착지할 때 찌그러짐과 먼지.
- **캐릭터 6종** — 각자 상시 특성 1개 + 게임 중 1회 스킬. 헤드리스 시뮬레이션 수백 판씩 돌려 승률을 20~29% 안에 맞췄습니다.
- **주사위 포인터** — 2~12를 오가는 포인터를 멈추면 그 숫자가 나올 확률이 크게 올라갑니다.
- **끌어오기** — 내 건물 도시에 도착하면 건물 크기(최대 3칸)만큼 양옆 플레이어를 끌어와 통행료를 받습니다.
- **핵폭탄** — 출발 칸에 정확히 도착하면 내 도시에서 핵폭탄을 쏴 양옆 건물을 무너뜨립니다(1인당 3발). 폭심지의 내 건물도 같이 무너지고 폐허에 잔해가 남습니다. 폭탄은 사정거리에 따라 모양이 다릅니다(별장 1칸: 도화선 둥근 폭탄 · 빌딩 2칸: 줄무늬 미사일 · 호텔/랜드마크 3칸: 낙하산 ☢ 핵탄두). 카메라가 떨어지는 폭탄을 따라가고, 착탄하면 범위가 붉게 그려진 뒤 범위 안 건물이 한꺼번에 무너집니다.
- **효과음** — Web Audio로 합성(외부 파일 없음). 화면 🔊 버튼으로 끌 수 있습니다.
- **3D 캐릭터 말 + 감정 표현** — 머리·몸·팔이 있는 캐릭터 말. 돈을 내면 울고, 받으면 웃고, 끌려가면 화냅니다. 감정을 표현할 때 고개를 들고 카메라가 잠깐 다가갑니다. 사람은 왼쪽 얼굴 버튼으로 직접 표현.
- **보이는 게임** — 돈이 오갈 때 말 위로 금액이 뜨고 코인이 날아가며 상단 토스트에 기록. 파산·인수·랜드마크·핵폭탄은 화면 중앙 큰 연출. 큰 통행료 직전엔 붉은 경고와 심장 소리.
- **판단 보조** — 포인터 숫자마다 그 칸에 서면 생기는 일(통행료·구매·끌어오기 인원·핵폭탄)이 표시되고, 독점까지 1곳 남은 상대는 경고와 함께 그 칸이 깜빡입니다.
- **행운카드** — 가운데에 실제 카드가 뒤집히며 나타나고, 카드 14종마다 배경·패턴·그림이 다릅니다. 탭하거나 5초 뒤 닫힘.
- **읽기 쉽게** — 타일마다 이름·금액을 큰 글씨 띠에, 소유자 색 줄, 마우스를 올리면 통행료·건설비·인수가·사정거리 툴팁. 플레이어 카드는 화면 크기에 비례해 커지고 고대비. 🏠 버튼으로 시점 초기화.
- **독점 효과** — 색 그룹을 독점하면 그 도시들 위에 황금빛 기둥·왕관·반짝임이 생깁니다(통행료 2배).
- **파산 규칙** — 돈이 모자라 파산해도 받는 사람은 통행료 전액을 받습니다(부족분은 은행이 지급).
- **핵폭탄 켜기/끄기** — 시작 화면에서 선택.
- **넉넉한 경제** — 시작 1,500만·월급 150만. 내 도시에 다시 오면 랜드마크까지 한 번에 지을 수 있습니다.
- **세계 이벤트** — 4라운드마다 올림픽·경기 침체·건설 붐·관광 시즌·대지진·랜드마크 배당 중 하나.
- **잭팟** — 세금·벌금·탈출비가 쌓이고 출발 칸에 정확히 서면 전부 획득. **꼴찌 구호금**: 꼴찌는 월급 2배.
- **축제** — 줄무늬 천막·회전 조명·색종이·“축제 ×2” 간판·불꽃놀이로 크게 표시.
- **유물(로그라이크)** — 출발을 지날 때마다 유물 3개 중 1개 선택(최대 6개): 🧲 강력 자석 · 🩸 흡혈 계약 · 🏗️ 속성 공사 · 🎲 납 주사위 · 🛡️ 파산 보험 · ☢️ 핵 탄두 · 🎟️ 잭팟 사냥꾼 · 👑 독점 왕관 · 💼 연봉 협상 · 🏷️ 할인 쿠폰.
- **판마다 바뀌는 칸** — 행운카드 칸 2~3곳이 🎰 카지노(홀짝 베팅) · 🔨 경매장(빈 땅 비공개 입찰) · 🕶️ 암시장(유물 300만)으로 무작위 변경.
- **마일리지** — 판이 끝나면 순위·랜드마크·유물 수만큼 적립(브라우저 저장). 시작 화면에서 +500만 · 시작 유물 · 핵폭탄 +1 · 면제권 2장을 구매.
- **🌏 세계 일주 런** — 시작 화면 모드에서 선택. 아시아 → 유럽 → 아메리카 3스테이지, 사람 플레이어가 이기면 유물을 들고 다음 스테이지로(+새 유물). AI는 스테이지마다 자금·유물이 늘고, 마지막 스테이지엔 3턴마다 땅을 강제 인수하는 👑 재벌 회장 보스가 등장. 클리어 보너스 마일리지.
- **배경음악·효과음** — 모두 WebAudio로 즉석 합성(음원 파일 없음). 상황에 따라 바뀌는 5곡(평상시 · 긴박 · 보스 · 무인도 · 꼴찌 위기)과 큰 사건 때의 짧은 스팅어, 🎵 버튼으로 끄고 켬(저장). 포인터 명중, 자석, 건설, 랜드마크 팡파르, 파산, 카드, 세계여행, 카지노, 경매, 무인도 호송·탈출, 감정 표현마다 전용 효과음.
- **턴 제한 시간** — 15/30/60초. 시간이 끝나면 주사위는 자동, 선택은 안전한 쪽으로.
- **휴대폰 가로 고정** — 세로로 들어도 화면을 가로로 돌려 보드 전체가 보입니다. 로그는 📜 버튼으로 열기 전까지 숨김.

## 캐릭터

| 캐릭터 | 특성 | 스킬 (1회) |
|---|---|---|
| 🧭 모험가 | 세계여행 칸에서 즉시 이동, 월급 +80만 | 순간이동: 통행료를 낼 때 절반만 내고 원하는 칸으로 도망 |
| 👷 건축가 | 건설비 35% 할인 | 긴급 공사: 건설할 때 무료 두 단계, 호텔까지 (땅 살 때 별장+빌딩 무료) |
| 💰 상인 | 받는 통행료 +70% | 바가지: 상대가 내 땅에 온 순간 그 통행료 3배 |
| 🍀 행운아 | 포인터 명중률 80%, 나쁜 카드 다시 뽑기, 카드 수입 2배 | 운명의 주사위: 나쁜 칸에 떨어지면 숫자를 골라 다시 던짐 |
| 🤝 협상가 | 내는 통행료 30% 할인 | 외교 면책: 통행료를 낼 때 이번 한 번 면제 |
| ⚓ 선장 | 무인도 1턴, 관광지 40% 할인·관광지 통행료 면제 | 폭풍 소환: 무인도에 갇힐 때 상대를 대신 보내거나, 120만 이상 통행료를 낼 때 땅 주인을 무인도로 날리고 면제 |

스킬은 미리 누르는 게 아니라 **쓸 수 있는 상황이 오면 그 자리에서 물어봅니다.**

## 구조

빌드 과정이 없는 정적 사이트입니다.

```
index.html     게임 전체 (HTML + CSS + JS 모듈, Three.js는 jsDelivr CDN)
favicon.svg
.github/workflows/pages.yml   main에 push하면 GitHub Pages로 자동 배포
```

## 로컬 실행

ES 모듈과 import map을 쓰므로 파일을 직접 열지 말고 정적 서버로 띄웁니다.

```bash
npx -y http-server@14.1.1 -p 8765 -c-1
```

그다음 http://localhost:8765 를 엽니다. 같은 Wi‑Fi의 휴대폰에서는 `http://<PC IP>:8765` 로 접속할 수 있습니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 배포합니다. 별도 설정은 필요 없습니다.
