# 지구한바퀴 (Earth Lap)

캐릭터를 골라 세계 도시를 사고, 건물을 올리고, 독점하는 4인 3D 보드게임입니다.
사람이 고르지 않은 자리는 AI가 플레이합니다. 설치 없이 브라우저(PC·휴대폰)에서 바로 할 수 있습니다.

**플레이:** https://simsimhugh.github.io/earth-lap/

## 특징

- **3D 보드** — Three.js(WebGL). 현재 플레이어를 따라가는 카메라, 바다·섬·구름 배경, 블룸 효과.
- **캐릭터 6종** — 각자 상시 특성 1개 + 게임 중 1회 스킬. 헤드리스 시뮬레이션 수백 판씩 돌려 승률을 20~29% 안에 맞췄습니다.
- **주사위 포인터** — 2~12를 오가는 포인터를 멈추면 그 숫자가 나올 확률이 크게 올라갑니다.
- **끌어오기** — 내 건물 도시에 도착하면 건물 크기(최대 3칸)만큼 양옆 플레이어를 끌어와 통행료를 받습니다.
- **핵폭탄** — 출발 칸에 정확히 도착하면 내 도시에서 핵폭탄을 쏴 양옆 건물을 무너뜨립니다(1인당 3발). 폭심지의 내 건물도 같이 무너지고 폐허에 잔해가 남습니다. 카메라가 떨어지는 폭탄을 따라가고 건물이 파편을 튀기며 무너집니다.
- **효과음** — Web Audio로 합성(외부 파일 없음). 화면 🔊 버튼으로 끌 수 있습니다.
- **3D 캐릭터 말 + 감정 표현** — 머리·몸·팔이 있는 캐릭터 말. 돈을 내면 울고, 받으면 웃고, 끌려가면 화냅니다. 감정을 표현할 때 고개를 들고 카메라가 잠깐 다가갑니다. 사람은 왼쪽 얼굴 버튼으로 직접 표현.
- **보이는 게임** — 돈이 오갈 때 말 위로 금액이 뜨고 코인이 날아가며 상단 토스트에 기록. 파산·인수·랜드마크·핵폭탄은 화면 중앙 큰 연출. 큰 통행료 직전엔 붉은 경고와 심장 소리.
- **판단 보조** — 포인터 숫자마다 그 칸에 서면 생기는 일(통행료·구매·끌어오기 인원·핵폭탄)이 표시되고, 독점까지 1곳 남은 상대는 경고와 함께 그 칸이 깜빡입니다.
- **턴 제한 시간** — 15/30/60초. 시간이 끝나면 주사위는 자동, 선택은 안전한 쪽으로.
- **휴대폰 가로 고정** — 세로로 들어도 화면을 가로로 돌려 보드 전체가 보입니다. 로그는 📜 버튼으로 열기 전까지 숨김.

## 캐릭터

| 캐릭터 | 특성 | 스킬 (1회) |
|---|---|---|
| 🧭 모험가 | 세계여행 칸에서 즉시 이동, 월급 +20만 | 순간이동: 통행료를 낼 때 절반만 내고 원하는 칸으로 도망 |
| 👷 건축가 | 건설비 15% 할인 | 긴급 공사: 건설할 때 무료 두 단계, 호텔까지 (땅 살 때 별장+빌딩 무료) |
| 💰 상인 | 받는 통행료 +70% | 바가지: 상대가 내 땅에 온 순간 그 통행료 3배 |
| 🍀 행운아 | 포인터 명중률 90%, 나쁜 카드 다시 뽑기, 카드 수입 2배 | 운명의 주사위: 나쁜 칸에 떨어지면 숫자를 골라 다시 던짐 |
| 🤝 협상가 | 내는 통행료 20% 할인 | 외교 면책: 통행료를 낼 때 이번 한 번 면제 |
| ⚓ 선장 | 무인도 1턴, 관광지 40% 할인·관광지 통행료 면제 | 폭풍 소환: 무인도에 갇힐 때 상대를 대신 보내거나, 120만 이상 통행료를 낼 때 땅 주인을 무인도로 날리고 면제 |

스킬은 미리 누르는 게 아니라 **쓸 수 있는 상황이 오면 그 자리에서 물어봅니다.**

## 구조

빌드 과정이 없는 정적 사이트입니다.

```
index.html     게임 전체 (HTML + CSS + JS 모듈, Three.js는 jsDelivr CDN)
favicon.svg
.github/workflows/pages.yml   main에 push하면 GitHub Pages로 자동 배포
```

## 로컬 실행

ES 모듈과 import map을 쓰므로 파일을 직접 열지 말고 정적 서버로 띄웁니다.

```bash
npx -y http-server@14.1.1 -p 8765 -c-1
```

그다음 http://localhost:8765 를 엽니다. 같은 Wi‑Fi의 휴대폰에서는 `http://<PC IP>:8765` 로 접속할 수 있습니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 배포합니다. 별도 설정은 필요 없습니다.
